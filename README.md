# Atelier5_2_CRUD
Cet atelier a pour objectif de mettre en œuvre une application web de type CRUD. Ce sigle désigne les quatre opérations de base sur  des données : Create (créer), Read (lire), Update (modifier) et Delete (supprimer). L’application gère une table d’exercices (titre,  auteur, date de création) stockée dans une base de données MySQL
